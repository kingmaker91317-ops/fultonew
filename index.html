API contract - /api/v1/software/init

What the client (Fluorite binary) sends and expects back.

POST /api/v1/software/init Headers: Content-Type: application/json X-Emerite-Sig: true Body (client -> server): { "key": "FLR-XXXX-XXXX-XXXX", "hwid": "device-hwid", "cpu": "Str...", "ram_free_kb": "4058192", "ip_wifi": "192.168.1.5", "init_base_offset": "0x3601550" } Response (server -> client): { "status": "ok", "message": "Auth Success! Plan: WEEK | Expiry: 2026-09-19 12:00", "plan": "WEEK", "expiry": "2026-09-19T12:00:00Z", "hwid": "locked-hwid" } Failure responses: "key not found", "key is currently paused.", "key invalid.", key is banned/hwid-mismatch.
